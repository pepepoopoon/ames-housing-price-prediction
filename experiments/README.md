# Эксперименты на синтетическом Ames benchmark

Каталог содержит 85 фактически выполненных offline-запусков. Для каждого запуска сохранён
отдельный JSON с полной конфигурацией, размерами train/validation/test, метриками кандидата и
`DummyRegressor`, ошибками по сегментам и реализованным объёмом искажений данных. Генерация,
разбиение и обучение детерминированы указанными в JSON значениями `seed`.

## Состав запусков

| Семейство | JSON | Что измеряется |
| --- | ---: | --- |
| Learning curve | 15 | Зависимость validation MAE от доступной доли train |
| Seed stability | 14 | Полный повтор генерации, split и обучения на четырёх seed |
| Ridge alpha | 12 | Регуляризация от `0.1` до `50` |
| Random Forest | 12 | Число деревьев, глубина и минимальный размер листа |
| Gradient Boosting | 12 | Число деревьев, глубина и learning rate |
| Data quality | 12 | Пропуски, дубликаты, шум цели и комбинированный сценарий |
| Inference stress | 8 | Пропуски, неизвестный район, сдвиг площади и числовой шум |

Всего измерено 61 конфигурация Ridge, 12 Random Forest и 12 Gradient Boosting. Во всех 85
запусках кандидат показал меньший test MAE, чем медианный baseline на том же holdout.

## Основные наблюдения

- В 15 learning curves медианное снижение validation MAE от минимальной до полной доли train
  составило **24.68%**; диапазон по запускам — от **6.35%** до **36.10%**.
- В 14 stability-отчётах выполнено 56 независимых повторов. Медианный коэффициент вариации
  test MAE равен **6.49%**, диапазон — **2.79–15.41%**.
- Самый сильный из проверенных inference-сдвигов — одновременное увеличение `GrLivArea` и
  `LotArea` на 25%: MAE вырос на **12 413.81** относительно чистого test в том же запуске.
- При 30% домов из неизвестного района MAE вырос на **1 673.35**, а при 30% числового шума —
  на **872.12**. Эти дельты считаются внутри одного holdout и потому пригодны для сравнения с
  чистым состоянием соответствующего запуска.
- Медианный test MAE по всем 85 артефактам равен **21 805.76**. Это описательная сводка:
  разные seed создают разные синтетические выборки, поэтому ранжировать модели только по этому
  общему числу нельзя.

Каждый JSON также содержит MAE, RMSE и средний residual по районам, уровням качества и эпохам
строительства. Это позволяет проверять не только агрегированную метрику, но и локальные
провалы качества.

## Воспроизведение запуска

Пример learning curve:

```bash
PYTHONPATH=src python -m ames_housing.experiments \
  --output /tmp/ames-learning.json \
  --label local-learning-check \
  --seed 1101 \
  --rows 160 \
  --learning-fractions 0.25,0.5,0.75,1.0
```

Пример stress-проверки:

```bash
PYTHONPATH=src python -m ames_housing.experiments \
  --output /tmp/ames-stress.json \
  --label local-area-shift \
  --seed 7217 \
  --rows 360 \
  --stress area_scale \
  --stress-level 0.25
```

Артефакты основаны на локальном синтетическом генераторе и проверяют инженерное поведение
pipeline. Они не заменяют оценку на зафиксированной версии реального датасета Ames.
