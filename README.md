# Прогноз стоимости недвижимости Ames

## Описание задачи

Регрессия цены продажи дома по признакам, доступным до сделки. Цель — `SalePrice`; идентификаторы и сама цель исключены из признаков.

## Цель проекта

Получить воспроизводимый ориентир для оценки объектов. Основная метрика — MAE в денежных единицах, дополнительно считаются RMSE и R².

## Архитектура решения

Проверка схемы, конечности чисел и положительной цены → фиксированные
train/validation/test → preprocessing внутри `Pipeline` → Dummy median, Linear Regression,
Ridge, Lasso, Random Forest и Gradient Boosting. Линейные модели обучаются на
`log1p(SalePrice)`. На train выполняется 3-fold CV, модель выбирается по validation MAE, test
открывается только в `evaluate`. Границы дешёвых/средних/дорогих домов вычисляются только на
train. Перед evaluate/predict проверяются точный порядок признаков и интерфейс модели в
сохранённом артефакте.

## Структура каталогов

`src/ames_housing` — схема, модели и CLI; `tests` — offline-проверки; `data` — контракт; локальные `artifacts` и `reports` игнорируются; `.github/workflows` запускает CI.

## Используемые технологии

Python 3.11, NumPy, pandas, scikit-learn, joblib, pytest, Ruff.

## Требования к окружению

Python 3.11.15; совместимые версии закреплены в `pyproject.toml`.

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
python -m pip install -e ".[dev]"
```

## Подготовка данных

Контрольный источник — [OpenML house_prices, id 42165](https://www.openml.org/d/42165).
В метаданных OpenML поле лицензии имеет значение `NA`, поэтому право на распространение
исходных строк не подтверждено и реальные данные в репозиторий не включены. Локальные
версия файла, размер и SHA-256 отсутствуют; их нужно зафиксировать перед полным
экспериментом. Для автономного smoke-run используйте `make smoke`.

## Запуск обучения

```bash
ames-train --data data/smoke.csv --artifact artifacts/model.joblib --report reports/validation_metrics.json
```

## Запуск оценки

```bash
ames-evaluate --data data/smoke.csv --artifact artifacts/model.joblib --metrics reports/test_metrics.json --errors reports/largest_errors.csv
```

## Запуск инференса

```bash
ames-predict --data data/smoke.csv --artifact artifacts/model.joblib --output reports/predictions.csv
```

## Метрики

MAE — основная; RMSE сильнее штрафует крупные промахи, R² дан как дополнительный ориентир. Отдельный отчёт сравнивает MAE на дешёвом, среднем и дорогом сегментах и сохраняет крупнейшие остатки.

## Тестирование

`make check` запускает Ruff и pytest. Тесты используют только локально сгенерированные данные, без сетевых загрузок.

## Ограничения

OpenML-версии могут различаться схемой и лицензией. Исторические цены не переносятся напрямую на другой рынок или период. Smoke-данные не пригодны для оценки качества; перед применением нужны временная проверка и анализ дрейфа.

## Полученные результаты

Метрики на зафиксированной реальной версии Ames пока не получены и не выдумываются. В README будут добавлены только результаты централизованного test-запуска; smoke-метрики служат технической проверкой.
